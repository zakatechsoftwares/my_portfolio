# Dr. Saka Shittu — Portfolio (Next.js + Tailwind)

This is a minimal, ready-to-deploy starter for a portfolio homepage focused on case studies (clinician + developer).

## Quick start
1. Install dependencies:
   ```
   npm install
   ```
2. Run dev server:
   ```
   npm run dev
   ```
3. Build:
   ```
   npm run build
   npm start
   ```

## Deploy
- Deploy to Vercel (recommended) — connect the repo and Vercel will detect Next.js.
- Or use any platform supporting Node.js.

## Notes
- Replace placeholder images & email addresses.
- If you prefer the app directory (Next.js 13+), you can migrate pages to /app easily.
